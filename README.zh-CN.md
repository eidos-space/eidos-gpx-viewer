# GPX 查看器

以只读文件视图浏览 GPX 轨迹、路线和航点。

需要 **Eidos Lite 0.29.0** 及以上版本、插件 API **3.7.0**、WebGL 和打包的浏览器 Worker。从插件市场或项目的 GitHub Release 安装，在 Space 启用后打开 `.gpx` 文件，选择 **GPX 地图**。插件 ID 是 `eidos.gpx-viewer`；使用其他 ID 的安装包属于独立安装。

名称、控件、提示和文档跟随宿主语言。切换语言保留当前轨迹点、播放状态和地图位置，不会重新读取文件。

## 浏览路线

- 文件包含多个轨迹、路线或航点集合时，可使用选择器切换，全程按钮适应所选路线。
- 拖动时间轴查看坐标、时间、海拔和速度，按记录时间以 1×、10×、60× 或 300× 播放。
- 时间缺失、重复或逆序时禁止播放，仍可浏览各点；分段之间保留时间空档。
- 详情显示点数、分段数及海拔／速度曲线。曲线横轴是轨迹点，缺失值和分段边界会断开。
- 优先使用 Waylog 扩展或 GPX 1.0 中的速度，否则按同一分段内相邻带时间的点推算。
- 刷新重新读取文件，失败时保留上次成功内容并显示错误；重试底图只重新加载瓦片，不重读 GPX。

## 格式、隐私与限制

支持 UTF-8 GPX 1.0/1.1、默认或带前缀命名空间、`trk`/`trkseg`、`rte` 和 `wpt`。缺少命名空间时会警告后兼容读取。核心 `ele` 表示海拔，不使用椭球高替代缺失的海拔；忽略未知扩展。

限制为 16 MiB 和 100,000 个轨迹点。非法坐标会被跳过、发出警告并使连线断开；拒绝 DTD 和实体声明。绘图会断开经度回绕处，跨日期变更线的路线适应全程时可能显示较宽的世界视图。

插件只读取绑定文件，不能编辑。OpenFreeMap 会收到视口瓦片请求和普通网络信息；GPX 内容保留在本机，除非你明确发布文件。发布会包含可读取的文件和插件副本。底图加载失败不影响轨迹、图表和播放，不提供离线区域下载。CLI Serve 及当前移动端宿主不支持此归档，已有旧版安装可继续使用。

保留 MapLibre BSD 许可，以及 OpenFreeMap、OpenMapTiles 和 OpenStreetMap 的署名。

## 开发

使用 Node.js 22.12 及以上版本和 SDK/tools 0.9.0。依次运行 `npm ci`、`npm run prepare:map`、`npm test`、`npm run check -- --target lite` 和 `npm run pack:plugin`。浏览器测试使用 Google Chrome 和合成 GPX 数据。
